This is a basic unzipping script for unzipping a batch of zipped files into a single directory. This code does not check if you have enough space to unzip first.

Originally designed for use on Windows 11. 

1. Open the script in VSCode
2. Set extractionFolder to the directory where your .zip files are located. -- THIS WILL UNZIP EVERY ZIPPED FILE IN THE FOLDER. Ex. Setting the Downloads folder "C:\Users\User_01\Downloads" will Unzip every zipped file in Downloads.
4. Set destinationFolder to directory.
5. Run the script.
